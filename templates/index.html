PROJECT OVERVIEW

What powers Verifier Lense?

The system combines text preprocessing, feature extraction and supervised machine learning.

01

Text Preprocessing

The submitted news text is cleaned before being transformed into numerical features.

02

TF-IDF Vectorization

Text is converted into numerical representations using the trained TF-IDF vectorizer.

03

Logistic Regression

The trained classification model predicts the category of the submitted news article.

04

Prediction Output

The application displays the predicted category and the model's confidence score.

MACHINE LEARNING MODEL

Built around text classification.

Verifier Lense uses a trained Logistic Regression classifier with TF-IDF feature extraction. The model processes textual patterns learned during training and predicts whether submitted content belongs to the real or fake news category. Its output is a machine-learning prediction, not independent verification of the article's factual accuracy.
