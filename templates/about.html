ABOUT THE PROJECT

About Verifier Lense

A Bachelor of Computer Applications mini project focused on machine-learning-based fake news classification.

PROJECT INTRODUCTION

What is Verifier Lense?

Verifier Lense is a machine-learning-based text classification application designed to categorize submitted news articles into real-news and fake-news classes. The system uses Natural Language Processing techniques, text preprocessing, TF-IDF feature extraction and a trained Logistic Regression classifier to generate predictions. It provides an interactive web interface through which users can submit news text and view the model's prediction along with its confidence score.

PROJECT SCOPE & LIMITATIONS

Understanding the system's scope

Verifier Lense performs machine-learning-based text classification. It does not independently verify news claims, retrieve live news reports or guarantee factual accuracy. Its predictions depend on patterns learned from the training dataset and should be treated as classification outputs rather than definitive judgments.
