MODEL ARCHITECTURE

How the classification model works

Verifier Lense uses a supervised machine learning approach combining TF-IDF feature extraction with a Logistic Regression classifier.

01

Input Text

The news article is submitted as textual input.

02

Preprocessing

Text cleaning prepares the article for feature extraction.

03

TF-IDF

Text is converted into numerical features using Term Frequency-Inverse Document Frequency.

04

Classification

Logistic Regression predicts the real or fake category.

TECHNICAL COMPONENTS

Technologies used

TF-IDF Vectorizer

Converts text into numerical feature representations based on word importance.

Logistic Regression

A supervised classification algorithm used to predict the category of news articles.

Flask

Provides the web application interface and connects user input with the trained model.

MODEL LIMITATIONS

What the model cannot guarantee

The classifier identifies textual patterns learned from its training data. It does not independently verify claims, consult live news sources, or establish the factual accuracy of an article. Its predictions may be affected by unfamiliar topics, changing language patterns, misleading text and limitations in the training dataset.
