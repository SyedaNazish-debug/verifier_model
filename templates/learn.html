Learn & Understand

Understand the concepts and technologies used in machine-learning-based news classification.

01 · FUNDAMENTALS

What is Natural Language Processing?

Natural Language Processing (NLP) is a branch of Artificial Intelligence that enables computers to process, analyze and understand human language. It is used in applications such as chatbots, language translation, sentiment analysis and text classification.

How NLP relates to Verifier Lense

Verifier Lense processes news articles as text and prepares them for machine learning classification.

02 · TEXT PREPARATION

Text Preprocessing

Text preprocessing is the process of cleaning and preparing raw text before it is supplied to a machine learning model. News articles may contain unnecessary spaces, URLs, publisher references and other text elements.

Why is it important?

Cleaning text helps maintain consistency between the text used during model training and the text submitted during prediction.

Preprocessing in this project

Verifier Lense uses a custom text-cleaning function to remove selected unwanted text patterns and normalize whitespace before feature extraction.

03 · FEATURE EXTRACTION

TF-IDF Vectorization

TF-IDF stands for Term Frequency-Inverse Document Frequency. It is a statistical technique used to represent text numerically based on the importance of words in a document relative to a collection of documents.

Two main components

TF

Term Frequency

Measures how frequently a term appears in a document.

IDF

Inverse Document Frequency

Reduces the weight of terms that appear frequently across many documents.

Why does Verifier Lense use TF-IDF?

The trained vectorizer converts news text into numerical features that can be processed by the Logistic Regression classifier.

04 · CLASSIFICATION

Logistic Regression

Logistic Regression is a supervised machine learning algorithm commonly used for classification tasks. It estimates the probability of an input belonging to a particular class and uses a decision rule to assign the predicted category.

Application in this project

Verifier Lense uses a trained Logistic Regression classifier to categorize the numerical text features into real-news or fake-news classes.

REMEMBER

Classification is not fact-checking.

A machine learning model learns patterns from its training dataset. Its prediction does not independently establish whether a news claim is true or false. Always consult reliable sources and independent fact-checking resources when evaluating information.
